# Project Setup Instructions

## Create a New Project
- Create a new project either in **GitLab** or **GitHub**.

## Build and Release
- Use **Docker** for build and release.

## Project Structure
- Separate source code and configuration files. Ensure logging is implemented for tracing purposes:
- **Source Code**
- **Config File** (e.g., `xxx.ini`, `xxx.json`, `xxx.yaml`):
```bash
  smtp_server=''
  user=''
  password=''
```

## Dependency Management
- Manage 3rd party dependency as **requirements.txt** or **pyproject.toml** 
```bash
    dotenv 
    excel reader 
    pdf writer 
    email sender  
    logging 
```

## Automation Tasks 
```bash
  Read Payslip Data:
    Read records from payslip-202507.xlsx.

  Generate Salary Details:
    Create a PDF file with salary details.
    Encrypt it using the last 4 digits of the employee ID.

  Send Emails:
    Trigger an email to each individual employee with their salary details.
```
